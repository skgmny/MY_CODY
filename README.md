# 오늘의 옷장
https://my-cody-six.vercel.app/

내 옷을 사진으로 등록하고, 학교·데이트·운동 같은 상황에 맞는 코디를 찾아보는 모바일 웹 앱입니다. 추천 조합을 넘겨 보거나 상의·하의·신발을 직접 골라 코디를 저장할 수 있습니다.

## 사용 방법

처음 열면 옷장에 상의·하의·신발 예시가 3개씩 들어 있습니다. 예시 옷으로 추천과 직접 코디를 체험한 뒤 필요 없는 예시는 옷장에서 삭제할 수 있습니다.

1. **내 옷장**에서 사진을 찍거나 사진 보관함에서 최대 10장을 선택합니다. 사진마다 자를 범위를 정하고 확인하면 브라우저에서 배경을 자동으로 제거합니다. 앱이 제안한 품목 종류와 상황 태그는 저장 전에 바꿀 수 있습니다.
2. **누끼 수정**에서 지우기 브러시로 남은 배경을 없애고, 복원 브러시로 잘린 옷 부분을 되살립니다. 옷을 등록한 뒤에도 수정하거나 원본 배경으로 전환할 수 있습니다.
3. **코디 추천**에서 상황을 고르거나 건너뜁니다. 상황을 고르면 해당 태그가 붙은 옷을 우선 사용하고, 후보가 없는 품목은 태그 없는 옷으로 채웁니다. 가능한 조합은 무작위 순서로 한 번씩 표시합니다.
4. **직접 코디**에서는 상의·하의·신발을 세로로 확인합니다. 각 품목의 이전·다음 버튼을 누르거나 사진을 눌러 교체합니다. 옷장에서 여러 벌을 먼저 선택하면 선택한 옷 안에서 조합할 수 있습니다.
5. **저장 코디**에서 상황별로 코디를 찾아보고, 상세 화면에서 제목·상황·메모를 수정합니다. 변경사항은 자동으로 저장됩니다. 메모는 두 줄까지 표시되며 누르면 전체가 펼쳐집니다. 옷과 저장 코디는 각각 여러 개를 선택해 한 번에 삭제할 수 있습니다.

앱 설치와 공유 수신은 운영 빌드를 localhost 또는 HTTPS에서 열어 확인합니다. 화면별 요구사항과 완료 조건은 [PRD.md](PRD.md)에 정리되어 있습니다.
